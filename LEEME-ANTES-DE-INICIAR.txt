GameTrack - Entrega actualizada

Incluye:
- Frontend React + Tailwind.
- Backend Node.js + Express.
- PostgreSQL + Sequelize.
- Microservicio de recomendaciones en Python + FastAPI.
- Catálogo global RAWG, búsqueda por plataforma y ordenamiento por popularidad, nombre, fecha y Metacritic.
- Biblioteca personal con estados y opción de marcar/desmarcar favoritos.
- Recomendaciones y exportación PDF/JPG.
- Registro e inicio de sesión con correo/contraseña, bcrypt y JWT.
- Docker Compose.

IMPORTANTE:
1. Este ZIP no incluye .env ni secretos. Usa .env.example como plantilla.
2. OAuth 2.0 / OpenID Connect con un proveedor externo todavía requiere integración/configuración; no se debe considerar implementado en esta entrega.
3. La protección CSRF explícita y las pruebas de carga deben revisarse antes de afirmar cumplimiento completo de todos los requisitos no funcionales.

Instalación en Windows:
1. Extrae la carpeta GameTrack en C:\GameTrack.
2. Copia .env.example como .env.
3. Edita .env y configura POSTGRES_PASSWORD, JWT_ACCESS_SECRET, JWT_REFRESH_SECRET, AI_SERVICE_API_KEY y RAWG_API_KEY.
4. Ejecuta PowerShell:
   cd C:\GameTrack
   docker compose up -d --build
5. Abre http://localhost:3000

Si ya tienes una base de datos creada, haz una copia de seguridad antes de actualizar. El backend intenta agregar la columna favorite si no existe.
